## Project Overview

This project is a Tic-Tac-Toe game developed in Java where a human player competes against the computer.
The game is implemented using object-oriented programming principles and supports a configurable board size and win condition.

The application is structured around a clear separation of responsibilities:
- `Game` manages the game state, board logic, win detection, and round progression
- `Player` is an abstract class defining common player behavior
- `User` handles human input via the console
- `Computer` implements a basic AI using random valid moves
- `BoxSymbol` and `GameState` are enums used to represent board symbols and game status

Key features include:
- Turn-based gameplay
- Win, loss, and draw detection
- Input validation and exception handling
- Extendable logic for larger grids and different win conditions

Technologies used:
- Java
- Object-Oriented Programming (inheritance, abstraction, encapsulation)
